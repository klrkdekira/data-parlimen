## EXPLANATORY STATEMENT

This Bill seeks to amend the National Land Code (the "Code").

2. Clause 3 provides for a new Part One (B) to enable modifications to the Code to facilitate the implementation of the Pengurusan Danaharta Nasional Berhad Act 1998.

3. Clause 4 seeks to introduce a new Fifteenth Schedule that contains modifications to the Code to facilitate the implementation of the Pengurusan Danaharta Nasional Berhad Act 1998.
